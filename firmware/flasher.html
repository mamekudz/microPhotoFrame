⚡

📋 Anleitung:

  1. Verbinden Sie Ihr reTerminal via USB mit dem Computer
  2. Klicken Sie auf "Firmware Installieren"
  3. Wählen Sie im Dialog den COM-Port Ihres Geräts
  4. Warten Sie bis der Flash-Vorgang abgeschlossen ist
  5. Nach dem Neustart erscheint ein WiFi-Access-Point "microPhotoFrame"
  6. Verbinden Sie sich damit und konfigurieren Sie Ihr WLAN
