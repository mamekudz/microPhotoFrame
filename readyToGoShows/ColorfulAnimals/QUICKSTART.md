# 🚀 Quick Start: Colorful Animals Bilder

## Option 1: Unsplash Bilder herunterladen (Real Photos)

```bash
# Im Projekt-Root:
node scripts/downloadShowImages.mjs ColorfulAnimals
```

Das lädt alle 10 Unsplash-Bilder herunter in:

eadyToGoShows/ColorfulAnimals/ColorfulAnimals_orgimgs/

## Option 2: AI-Bilder generieren

Siehe **AI_PROMPTS.md** für detaillierte Prompts zum Generieren von stylisierten Tier-Kunstwerken wie dem Chamäleon.

### Empfohlene Tools:
- **Midjourney** (beste Qualität, kostenpflichtig)
- **DALL-E 3** via ChatGPT Plus (sehr gut)
- **Stable Diffusion** (kostenlos, lokal)

### Beispiel-Prompt:
```
A vibrant 3D sculptural chameleon, covered in intricate rainbow-colored 
geometric patterns of cyan, magenta, yellow, and orange. Glossy bead-like 
scale texture. Curled tail. Black background with dramatic lighting. 
Hyper-detailed, toy-like quality. 8K resolution.
```

## Nach dem Download/Generieren

1. Bilder in ColorfulAnimals_orgimgs/ ablegen
2. Webapp öffnen
3. Show 'ColorfulAnimals' erstellen
4. 'Add Photos' verwenden
5. 'Export Show' für ready-to-go ZIP
