# Quick Start: Classic Art

Zwölf gemeinfreie Gemälde für ein Farb-E-Ink-Display.

```bash
node tools/downloadShowImages.mjs ClassicArt
```

Lädt die Originale nach `readyToGoShows/ClassicArt/ClassicArt_orgimgs/`.

Danach in der Webapp:

1. Kanal wählen, Show `ClassicArt` anlegen
2. Photo Settings auf dasselbe Display wie die Show (z. B. reTerminal E1002)
3. Add Photos → Ordner `ClassicArt_orgimgs` wählen
4. Optional: Export Show für ein `.show`-Paket
